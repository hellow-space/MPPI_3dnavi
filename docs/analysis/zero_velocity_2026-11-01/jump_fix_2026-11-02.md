## 永久修复及运行态应用

`src/fishbot_navigation2/config/nav2_params_height_jump.yaml`：

```yaml
local_costmap:
  local_costmap:
    ros__parameters:
      plugins: ["inflation_layer"]
      inflation_layer:
        plugin: "nav2_costmap_2d::InflationLayer"
        enabled: false
```

纯 Jump 的局部地图原本就没有二维障碍源；保留插件名称用于 Humble 的 string[] 参数类型推断，但禁用这个占位层，防止其 reset 后的 current=false 阻塞控制器。HeightJumpCritic 的高程可行性检查继续启用；全局地图及 HeightObstacle 配置不改。

经用户批准，在 Domain 42 的运行节点应用同一参数：

```bash
ros2 param set /local_costmap/local_costmap inflation_layer.enabled false
```

返回 `Set parameter successful`，没有重启节点、重新设置起点或另发目标。Jump 启动脚本明确读取源码目录中的这份配置，因此下次使用原脚本启动也会生效，无需重新编译。
